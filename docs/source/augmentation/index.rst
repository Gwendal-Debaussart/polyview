Augmentation
============

View augmentation utilities that generate multiple views from a single input
matrix, including random projections, random subspaces, and kernel-based view
generation, plus :class:`~polyview.augmentation.view_splitter.ViewSplitter`,
which splits one matrix into views along its columns.
