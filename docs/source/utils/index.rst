Utilities
=========

Building blocks shared by several algorithm families, documented because they
are useful on their own: the kernel helpers let you inspect and precondition a
kernel before handing it to
:class:`~polyview.fusion.kernel_fusion.KernelFusion`, and the linear-algebra
helpers expose the truncated eigensolver the spectral methods are built on.
